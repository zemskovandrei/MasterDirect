# Telegram-бот: публикация в каталог

Мастер пишет боту → заполняет анкету → нажимает «Опубликовать» → карточка сразу появляется на сайте. Регистрация на сайте не нужна.

## Что уже есть на сайте

Пуш в `main` автоматически деплоит фронтенд (GitHub Pages) через `.github/workflows/deploy-pages.yml`.

Бот **не работает на GitHub Pages** — ему нужен постоянно запущенный Node API (тот же `npm run start:api`).

## Схема для мастера

Вы пишете мастеру одну фразу:

> Скиньте фото сюда, карточку поставлю сам.

Даёте ссылку на бота (`t.me/ваш_бот`), **не** пароль от сайта.

Бот спрашивает:

1. Имя  
2. Телефон  
3. Специальности (несколько галочек)  
4. Город + район  
5. До 5 фото работ  

После «Опубликовать» пишет строку в `specialist` и фото в `portfolio` / `portfolio_works`.

## Настройка

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.  
2. На сервере API в `.env`:

```env
TELEGRAM_BOT_TOKEN=123456:ABC...
SITE_ORIGIN=https://masterdirect.ge
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
```

3. Запуск:

```bash
npm run build:api
npm run start:api
```

В логах должно быть: `[catalog-bot] Telegram bot started`.

4. Напишите боту `/start` и пройдите тестовую анкету. Карточка появится в `/masters`.

## Где крутить API

Нужен хостинг с Node 22+: Railway, Render, Fly.io, VPS.  
GitHub Pages хостит только статику сайта; бот живёт рядом с Express API.

## Важно

- Публикуем **только** то, что мастер прислал сам.  
- Чужие объявления с nomerok / ss.ge / барахолки / чатов — нельзя.  
- Service role key должен быть только на сервере API, не во фронтенде.
